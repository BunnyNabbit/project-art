# Project art

A place for the original project files of the icons I create for my open source projects. All icons are marked as CC0 1.0 Universal.

I use _Picroma Plasma_ for vector graphics. This might make most of the original files mostly inaccessible as the tool reportedly never had a commercial release. In this case, their raster renders can be used. Not much can be done, but this is just the program I prefer the most to create vector graphics.
